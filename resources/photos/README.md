# Photos du site

Déposez vos photos dans ces dossiers : le site les redimensionne et les convertit tout seul (WebP, plusieurs tailles). Rien à coder.

| Dossier | Utilisation |
|---|---|
| `grossesse/` | Portfolio grossesse + page « Photographe grossesse à Dijon » |
| `nouveau-ne/` | Portfolio nouveau-né + page « Photographe nouveau-né à Dijon » |
| `famille/` | Portfolio famille + page « Photographe famille à Dijon » |
| `site/` | Photos nommées, voir ci-dessous |

## Ordre et rôle des photos

Les photos sont triées par nom de fichier : numérotez-les (`01-…`, `02-…`) pour choisir l'ordre.

Dans `grossesse/`, `nouveau-ne/` et `famille/` :

- la **1re** photo est la photo principale de la page de séance, de la carte d'accueil et de la couverture du portfolio ;
- les **2e et 3e** s'affichent en grand sur la page de séance ;
- les suivantes forment la galerie de la page de séance (9 max) ;
- **toutes** apparaissent dans le portfolio.

Dans `site/`, le nom du fichier compte :

| Fichier | Emplacement | Si absent |
|---|---|---|
| `accueil.jpg` | Grande photo en haut de l'accueil (format paysage) | 1re photo grossesse |
| `portrait.jpg` | Votre portrait : accueil et page « Mon univers » | emplacement vide |
| `bon-cadeau.jpg` | Page « Bon cadeau » | 2e photo famille |

## Texte alternatif (référencement)

Le nom du fichier sert de description pour Google et les lecteurs d'écran :
`03-ventre-rond-au-lac-kir.jpg` devient « Ventre rond au lac kir ».
Les noms d'appareil (`IMG_1234.jpg`) reçoivent une description générique.

## Export conseillé (Lightroom…)

- JPEG, qualité 80 à 90, espace colorimétrique **sRGB** ;
- **2400 px** maximum sur le grand côté (inutile d'envoyer les fichiers 24 Mpx).
